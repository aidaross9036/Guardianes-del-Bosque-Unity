# Guardianes del Bosque 🌲

**Guardianes del Bosque** es una aplicación interactiva desarrollada en Unity como parte de un proyecto académico de Diseño de Juegos por Aida Rosas Romero.

El proyecto se desarrolla de manera progresiva, incorporando diferentes elementos y funcionalidades conforme avanza el curso.

## Características actuales

- Interfaz adaptable a diferentes tamaños de pantalla.
- Navegación entre escenas y paneles.
- Botones interactivos.
- Control del tamaño de fuentes.
- Sprite arrastrable mediante interacción del usuario.
- Animaciones integradas mediante bucles de sprites.
- Animaciones de fogata, hojas y nubes con un mínimo de ocho frames.
- Escenas de menú principal y área de juego.

## Concepto

El proyecto está ambientado en un bosque que ha perdido su equilibrio natural. El jugador toma el papel de un guardián encargado de explorar, recolectar recursos y restaurar diferentes áreas del ecosistema.

## Tecnologías

- Unity
- C#
- TextMeshPro
- Universal 2D
